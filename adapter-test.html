Adapter test

Checks that your backend adapter gives the helpdesk everything it needs (see PLATFORM.md). Run it once signed in as a manager and once as an agent.

It writes a few documents to a _adaptertest collection and deletes them afterwards. Allow that collection while testing.

Tip: to try the built-in demo adapter, set the adapter to platform.example.js. Add &as=agent to this page's address to test as an agent.
